 Animax Tec - Plataforma de Streaming V.O.D. 🎬

Projeto académico desenvolvido para a disciplina de Engenharia de Requisitos. 
O sistema fornece serviços de reprodução de vídeo sob demanda, sistema de favoritos interativo, avaliações (1 a 5 estrelas) e interação comunitária, com base de dados relacional.

1) Tecnologias Utilizadas
Front-end: HTML5, CSS3, Vanilla JavaScript (Interface moderna, responsiva e com suporte a Alto Contraste).
Back-end: Java 21, Spring Boot.
Base de Dados Banco Relacional H2 e Spring Data JPA.

2) Como executar o projeto
1. Clone este repositório ou faça o download do código.
2. Execute a aplicação Spring Boot (ficheiro `AnimaxApplication.java`).
3. Abra o ficheiro `index.html` num navegador web (preferencialmente Google Chrome).
4. Dica: Registe um utilizador com a palavra `admin` no e-mail para desbloquear o Painel de Curadoria!

3) Documentação
Toda a documentação teórica (Diagramas, Regras de Negócio e Entrevistas) encontra-se na pasta `/docs`.
